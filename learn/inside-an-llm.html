What happens when you ask an LLM a question?

At a high level, a language model turns text into tokens, turns each token into a list of numbers (a vector), passes those numbers through many layers of a neural network called a transformer, and finally scores every possible next token. It picks one, adds it to the text, and repeats one token at a time until the response is complete.

Your text→Tokens→Vectors→Transformer layers→Next token↺

Key ideas to take away

  • Tokens aren't always words. Real tokenisers often split words into smaller pieces, so “tokenisation” might become “token”, “isation”.
  • Tokens start as vectors. Each token has an initial embedding. The transformer combines it with position and context as it processes the sequence. Lesson 04 explores embeddings for search.
  • Attention mixes in context. It lets each position draw on information from earlier tokens, but it is one part of the computation, not a full explanation of the model's “reasoning”.
  • The numbers are learned, in two stages. In pretraining, the model adjusts billions of internal numbers (its parameters) to get better at predicting the next token across vast amounts of text. Fine-tuning with instructions and human feedback then teaches it to follow requests, which is why chat tools behave like assistants rather than autocomplete.
  • Output is a probability, then a choice. The model scores possible next tokens; a decoding setting such as temperature decides how adventurous the pick is. Lesson 03 lets you try this.

From scores to probabilities: softmax

The final layer produces a score (a logit) z for every token in the vocabulary, which often contains 50,000 to 200,000 tokens. Softmax turns scores into probabilities that add up to 1:

P(token i) = exp(z_i / T) / Σ_j exp(z_j / T)

T is the temperature. With T close to 0 the top token almost always wins; higher T flattens the distribution.

Attention in one line

Attention(Q, K, V) = softmax( Q·Kᵀ / √d_k ) · V

d_k is the length of each key vector. Dividing by its square root keeps the scores in a range where softmax still works well.

Each token produces a query (what am I looking for?), a key (what do I contain?) and a value (what do I pass on?). The query–key match decides how much of each value flows into the updated representation. In a causal language model, a token can only attend to itself and earlier tokens, which is why the grid in the lab is a triangle. Real models run many attention “heads” in parallel, in dozens of layers.

See real tokens in Python

from transformers import AutoTokenizer

tok = AutoTokenizer.from_pretrained("gpt2")
ids = tok("The charity team reviewed the tokenisation")["input_ids"]
print([tok.decode([i]) for i in ids])
